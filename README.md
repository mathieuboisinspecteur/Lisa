# Lisa

Outil d'aide à l'inspection en bâtiment au Québec (projet étudiant).

- Application web installable, utilisable sans réseau après la première ouverture.
- Toutes les données restent sur l'appareil de l'utilisateur. Aucune inspection n'est envoyée sur ce dépôt.
- Lisa est une aide : elle ne remplace pas le jugement du professionnel ni la validation par les organismes concernés.
